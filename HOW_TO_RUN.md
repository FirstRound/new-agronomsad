# 🚀 Как запустить проект "Собрано в саду"

## Способ 1: Python (самый простой, рекомендуется)

```bash
cd /workspace
python3 -m http.server 8080
```

Затем откройте в браузере: **http://localhost:8080**

## Способ 2: Node.js с serve

```bash
cd /workspace
npx serve .
```

## Способ 3: VS Code Live Server

1. Установите расширение "Live Server" в VS Code
2. Откройте файл `index.html`
3. Нажмите кнопку "Go Live" в правом нижнем углу

## Способ 4: Любой другой HTTP сервер

Проект требует HTTP сервер для работы ES6 модулей. Подойдет любой:
- Apache
- Nginx  
- PHP built-in server: `php -S localhost:8080`

---

## ❗ Важно

**Не открывайте index.html напрямую через file://** - ES6 модули не будут работать из-за CORS политики браузера.

Всегда используйте HTTP сервер!

---

## 🧪 Запуск тестов

### В браузере (полная поддержка):

1. Откройте `tests/run_tests.html` через HTTP сервер
2. Нажмите кнопку "Запустить все тесты"
3. Смотрите результаты

### Ограничения Node.js тестов:

Некоторые тесты не работают в Node.js, потому что код использует browser API (`document`, `window`). 
Для полного тестирования используйте браузер.

---

## 📱 Мобильное тестирование

Для тестирования на мобильном устройстве:

1. Узнайте IP адрес компьютера: `ip addr` или `ifconfig`
2. Запустите сервер: `python3 -m http.server 8080 --bind 0.0.0.0`
3. Откройте на телефоне: `http://ВАШ_IP:8080`

---

## 🔧 Требования

- Современный браузер (Chrome, Firefox, Safari, Edge)
- Python 3.x ИЛИ Node.js 14+
- Доступ к интернету для загрузки Leaflet.js и Google Fonts
