# 🌳 Гео-сервис: "Собрано в саду"

Модульное веб-приложение для визуализации и управления агрономическими данными на интерактивной карте.

## 🚀 Быстрый старт

### Вариант 1: Python (рекомендуется)
```bash
cd /workspace
python3 -m http.server 8080
```
Откройте в браузере: http://localhost:8080

### Вариант 2: Node.js
```bash
cd /workspace
npx serve .
```

### Вариант 3: VS Code Live Server
Установите расширение "Live Server" и нажмите "Go Live"

## 🧪 Запуск тестов

### В браузере (рекомендуется):
1. Откройте `tests/run_tests.html` в браузере
2. Нажмите кнопку "Запустить все тесты"

### В Node.js (ограниченная поддержка):
```bash
node tests/app.test.js
```

## 🔧 Архитектура

Приложение построено по модульному принципу с использованием ES6 классов:

- **AgroApp** - главный класс, координирует работу всех модулей
- **DataManager** - загрузка, парсинг, хранение и поиск данных
- **MapManager** - инициализация карты, добавление слоев, взаимодействие
- **SearchManager** - поиск по номерам участков, сортам, кластерам
- **FilterManager** - фильтрация по различным параметрам
- **StatsManager** - расчет статистики (площадь, деревья, кластеры)
- **ExportManager** - экспорт данных в CSV/Excel формат
- **TooltipManager** - отображение детальной информации при клике

## 📊 Функционал

### Основной
- ✅ Интерактивная карта с участками
- ✅ Поиск по номеру участка или сорту
- ✅ Детальная информация при клике
- ✅ Экспорт данных в Excel (CSV)
- ✅ Адаптивный дизайн для мобильных

### Расширенный
- ✅ Фильтрация по кластерам
- ✅ Статистика по площадям и деревьям

- ✅ Генерация WKT из GeoJSON
- ✅ Point-in-polygon проверки

## 📝 API

### DataManager
```javascript
const dm = new DataManager();
await dm.loadAllData();
dm.searchInData('query');      // Поиск
dm.filterData({cluster: 'A'}); // Фильтрация
dm.getStats();                  // Статистика
dm.getExportData();             // Данные для экспорта
dm.validateData();              // Валидация
```

### MapManager
```javascript
const mm = new MapManager('map', geoData);
mm.getMap();                    // Получить Leaflet map
mm.highlightFeature(id);        // Подсветить участок
mm.fitToFeatures();             // Показать все участки
```
