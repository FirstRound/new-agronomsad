# 🍎 Гео-сервис: Собрано в саду v2.0

Интерактивное веб-приложение для визуализации и управления агрономическими данными с расширенным функционалом.

## ✨ Новые возможности v2.0

### Функциональные улучшения
- ✅ **Фильтры** - по кластерам, сортам, возрасту деревьев
- ✅ **Статистика и дашборд** - площадь, количество деревьев, кластеров, сортов
- ✅ **Переключение слоев карты** - границы участков, номера, деревья
- ✅ **Инструменты измерения** - расстояние и площадь на карте

### UX/UI улучшения
- ✅ **Легенда** - цветовая схема культур
- ✅ **Мини-карта** - навигация по основной карте
- ✅ **Темная/светлая тема** - переключение и сохранение предпочтений
- ✅ **Печать карты** - оптимизированный вид для печати

### Технические улучшения
- ✅ **Кэширование данных** - localStorage для GeoJSON и статистики
- ✅ **Разделение на модули** - 13 независимых менеджеров
- ✅ **PWA поддержка** - manifest.json для установки как приложения

### Безопасность и данные
- ✅ **Валидация данных** - проверка формата GeoJSON при импорте
- ✅ **Импорт/экспорт** - загрузка своих данных и выгрузка в CSV
- ✅ **Версионирование** - кэш с версиями данных

### Расширенные функции
- ✅ **QR-коды** - генерация QR для каждого участка
- ✅ **Интеграция с погодой** - текущая погода через Open-Meteo API
- ✅ **Уведомления** - система toast-уведомлений о событиях

## 🚀 Быстрый старт

### Вариант 1: Python (рекомендуется)
```bash
cd /workspace
python3 -m http.server 8080
```

### Вариант 2: Node.js
```bash
cd /workspace
npx --yes http-server -p 8080
```

### Вариант 3: Без сервера (ограниченная функциональность)
Просто откройте `index.html` в браузере (некоторые функции могут не работать из-за CORS).

## 🌐 Доступ

Откройте в браузере: **http://localhost:8080**

## 🧪 Тесты

Откройте в браузере: **http://localhost:8080/tests/run_tests.html**

## 🎯 Использование

### Поиск
Введите номер участка или название сорта в поисковую строку и нажмите Enter.

### Фильтры
Используйте панель фильтров слева для выбора:
- Конкретного кластера
- Определенного сорта
- Возраста деревьев (ползунок)

### Измерения
1. Нажмите кнопку 📏 "Измерить"
2. Кликайте на карту для добавления точек
3. Двойной клик для завершения
4. Правый клик для отмены

Система покажет расстояние и площадь.

### Темы
Нажмите 🌓 для переключения между темной и светлой темой.

### Печать
Нажмите 🖨️ для печати карты (скроет панель управления).

### Импорт данных
1. Нажмите "📥 Импорт GeoJSON"
2. Выберите файл в формате GeoJSON
3. Данные автоматически отобразятся на карте

### Экспорт данных
Нажмите "📤 Экспорт CSV" для выгрузки всех данных в таблицу.

### QR-коды
Кликните на участок → в подсказке будет кнопка для генерации QR-кода с данными участка.

## 🔧 API Менеджеров

### DataManager
```javascript
import { DataManager } from './dataManager.js';
const dm = new DataManager();
await dm.loadAllData();
console.log(dm.parcels); // Массив участков
```

### MeasurementManager
```javascript
import { MeasurementManager } from './measurementManager.js';
const mm = new MeasurementManager(map);
mm.startMeasurement();
mm.setUpdateCallback((data) => {
    console.log(`Расстояние: ${data.distance}м, Площадь: ${data.area}м²`);
});
```

### WeatherManager
```javascript
import { WeatherManager } from './weatherManager.js';
const wm = new WeatherManager();
const weather = await wm.getWeather(55.7558, 37.6173);
console.log(`${weather.temperature}°C, ${weather.description}`);
```

### CacheManager
```javascript
import { CacheManager } from './cacheManager.js';
const cm = new CacheManager();
cm.set('key', { data: 'value' }, 3600000); // 1 час
const cached = cm.get('key');
```
