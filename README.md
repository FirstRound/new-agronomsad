# Собрано в саду - Гео-сервис для агрономических данных

Модульное веб-приложение для визуализации и управления данными садовых участков на карте.

## 🚀 Архитектура

### Модульная структура

Приложение построено по принципу разделения ответственности (Separation of Concerns):

1. **DataManager** - Загрузка, парсинг и хранение данных
2. **MapManager** - Инициализация карты, стилизация слоев
3. **SearchManager** - Поиск по номеру участка и сорту
4. **ExportManager** - Экспорт данных в CSV/JSON
5. **TooltipManager** - Отображение информации при клике/наведении
6. **FilterManager** - Фильтрация по кластерам, сортам, типам
7. **StatsManager** - Сбор и отображение статистики

### Класс AgroApp

Главный класс координирует работу всех менеджеров:

```javascript
class AgroApp {
    constructor() {
        this.dataManager = new DataManager();
        this.mapManager = null;
        this.searchManager = null;
        // ... другие менеджеры
    }
    
    async init() {
        await this.dataManager.loadAllData();
        this.mapManager = new MapManager('map', this.dataManager.geoData);
        // ... инициализация остальных
    }
}
```

## 🎯 Основные возможности

### 1. Визуализация на карте
- Отображение участков садов с геометрией
- Наложение кадастровых слоев
- Интерактивные метки с номерами участков

### 2. Поиск
- По номеру участка (например, "114")
- По названию сорта (например, "Имрус", "Хоней Крисп")
- Подсветка найденных участков синим цветом

### 3. Информация об участках
При клике на участок показывается:
- Сорт яблони
- Подвой
- Год посадки
- Фактическая площадь (га)
- Количество деревьев
- Тип сада (Интенсивный/Экстенсивный)
- Категория (Плодоносящее/Молодое дерево и т.д.)

### 4. Экспорт данных
- Полный экспорт в CSV с геометрией (WKT)
- Экспорт статистики
- Копирование в буфер обмена

### 5. Фильтрация
- По кластеру (D, E)
- По сорту
- По типу сада

### 6. Статистика
- Общее количество участков
- Общая площадь
- Общее количество деревьев
- Распределение по кластерам и типам

### Покрытие тестами

Тесты покрывают следующий функционал:

1. **DataManager**
   - Парсинг CSV данных
   - Парсинг GeoJSON
   - Извлечение fieldId
   - Получение сортов и кластеров
   - Статистика
   - Фильтрация
   - Генерация WKT

2. **MapManager**
   - Стили слоев
   - Алгоритм point-in-polygon

3. **ExportManager**
   - Форматирование CSV
   - BOM для UTF-8

4. **SearchManager**
   - Регистронезависимый поиск
   - Очистка запроса

## 🔧 Использование

### Подключение модулей

```javascript
import { DataManager } from './src/js/dataManager.js';
import { MapManager } from './src/js/mapManager.js';

const dm = new DataManager();
await dm.loadAllData();

const mm = new MapManager('map', dm.geoData);
```

### API DataManager

```javascript
// Получить все сорта
dm.getAllSorts();

// Получить статистику
dm.getStats();

// Фильтровать данные
dm.filterData({ cluster: 'E', sort: 'Имрус' });

// Экспорт данных
dm.getExportData();
```

## 📊 Структура данных

### CSV формат

| Колонка | Описание |
|---------|----------|
| Сезон | Год сезона (2025/2026) |
| № квартала | Номер участка (3.114) |
| Кластер | Группа участков (D, E) |
| Сорт | Название сорта |
| Подвой | Тип подвоя |
| Год посадки | Год высадки |
| Площадь (факт) | Фактическая площадь в га |
| Количество деревьев | Число вегетирующих деревьев |
| Категория сада | Тип категории |
| Тип сада | Интенсивный/Экстенсивный |

### GeoJSON формат

```json
{
  "type": "FeatureCollection",
  "features": [{
    "type": "Feature",
    "properties": {
      "name": "114",
      "fieldId": "114"
    },
    "geometry": {
      "type": "Polygon",
      "coordinates": [...]
    }
  }]
}
```
